# The PHP Vault

**Developer:** Cornelius Moore  
**Course:** CSC 4370 — Web Programming

## About the Game

The PHP Vault is an escape-room game where players solve three different puzzles to get out. Players will create an account, log in, and solve each puzzle before moving to the next room. Once they finish, they can see their final score on the leaderboard.

## Planned Features

- Login and registration
- Three puzzle rooms
- PHP sessions
- Hint system
- Leaderboard
- HTML and CSS design
